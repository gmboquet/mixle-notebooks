# mixle-notebooks 0.7.0 release checklist

**Status: in progress (nearly complete).** This release targets **mixle 0.7.0**. It renames the
working branch to `release/0.7.0`, adds a capability-showcase set of notebooks (now covering every
tracked 0.7.0 capability — see `notes/analysis.md`), reconciles two duplicate notebooks, updates the
docs, and — the core new gate — executes every shipped notebook against a clean `mixle==0.7.0`
install with the results recorded in an execution manifest (114/121 pass, 5 blocked, 2 slow/manual,
0 failures, 0 API breaks).

- Release branch: `release/0.7.0`
- Target library: `mixle==0.7.0` (installed from PyPI, not an editable dev tree)
- Checklist opened: 2026-07-10

See [`README.md`](README.md) for the status legend and evidence discipline this file follows.
